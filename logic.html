🎯 最終シグナル変換（スコア閾値）
強い買い スコア ≥ 75 複数指標が強い買いサイン。高い確度で上昇トレンド。
買い 60 ≤ スコア < 75 指標の過半数が買い方向。上昇局面の可能性が高い。
中立 40 ≤ スコア < 60 指標が混在。明確なトレンドなし。様子見推奨。
売り 25 ≤ スコア < 40 指標の過半数が売り方向。下落リスクあり。
強い売り スコア < 25 複数指標が強い売りサイン。下落トレンドの可能性大。

目標株価の計算式
ATR・52週高安値・SMAを組み合わせたリスク・リワード計算
📐 目標株価（リワード）の算出

買いシグナル時：ATR倍率ターゲット と 52週高値×係数 のうち高い方を採用。
売りシグナル時：ATR倍率ターゲット と 52週安値 のうち低い方を採用。

// 買いシグナル時 atrTarget = 現在株価 + ATR × targetMult high52wTgt = 52週高値 × high52wMult 目標株価 = max(atrTarget, high52wTgt) // 売りシグナル時 atrTarget = 現在株価 − ATR × targetMult 目標株価 = min(atrTarget, 52週安値)
ATR（Average True Range）= 直近14日の真の値動き幅の平均。相場のボラティリティを表します。
🛡 損切りライン（ストップロス）の算出
// 買いシグナル時（下方ストップ） rawStop = max( SMA − ATR × stopMult, 52週安値 ) if rawStop ≥ 現在株価: rawStop = 現在株価 − ATR × stopMult // 売りシグナル時（上方ストップ） rawStop = min( SMA + ATR × stopMult, 52週高値 ) if rawStop ≤ 現在株価: rawStop = 現在株価 + ATR × stopMult
⏱ ホライズン別パラメータ
ホライズン targetMult
(ATR倍率・目標)		 stopMult
(ATR倍率・損切)		 ストップ基準SMA 52週高安値
短期 × 1 × 0.5 SMA20 使用しない
中期 × 2 × 1 SMA20 使用する（×1.02）
長期 × 3 × 1.5 SMA50 使用する（×1.05）

⚡ リスク・リワード比率
R/R比率 = | リワード% | ÷ | リスク% | // 例: 目標 +6%, 損切 −3% → R/R = 2.0
投資判断の参考値です。将来の株価を保証するものではありません。
